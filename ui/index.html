Top 20 SQL Window Functions, Gaps & Islands & Statistical Outliers

1. DENSE_RANK() Run →

Find the Nth highest stock price without skipping ranks on ties

SELECT DENSE_RANK() OVER (ORDER BY last_price DESC)

2. PARTITION TOP-K Run →

Show the Top 3 stocks by trading volume for every exchange

ROW_NUMBER() OVER (PARTITION BY exchange ORDER BY volume DESC) <= 3

3. PERCENTILE_CONT Run →

Calculate the median and 95th percentile price per ticker

PERCENTILE_CONT(0.50) WITHIN GROUP (ORDER BY last_price)

4. FIRST_VALUE / LAST_VALUE Run →

Get session opening and closing prices within window partitions

FIRST_VALUE(last_price) OVER w / LAST_VALUE(...) OVER w

5. DEDUPLICATION Run →

Deduplicate stock snapshots keeping only the latest record

ROW_NUMBER() OVER (PARTITION BY ticker ORDER BY last_updated DESC) = 1

6. SLIDING WINDOW SMA Run →

Calculate 20-period simple moving average across price snapshots

AVG(last_price) OVER (ROWS BETWEEN 19 PRECEDING AND CURRENT ROW)

7. VWAP ALGORITHM Run →

Compute Volume Weighted Average Price (VWAP) for AAPL

SUM(last_price * volume) OVER w / NULLIF(SUM(volume) OVER w, 0)

8. RSI-14 MOMENTUM Run →

Calculate 14-period Relative Strength Index (RSI) momentum

RSI = 100 - (100 / (1 + AvgGain / AvgLoss))

9. CUMULATIVE RUNNING TOTAL Run →

Compute cumulative running total of traded volume throughout the day

SUM(volume) OVER (PARTITION BY ticker ORDER BY last_updated ROWS UNBOUNDED PRECEDING)

10. LAG() PERCENTAGE RETURNS Run →

Calculate bar-over-bar percentage price returns

(last_price - LAG(last_price) OVER w) / NULLIF(LAG(last_price) OVER w, 0)

11. ROLLING Z-SCORE Run →

Flag statistical price anomalies where Z-score > 2.0 standard deviations

ABS((last_price - mean) / NULLIF(stdev, 0)) > 2.0

12. GAPS & ISLANDS Run →

Find longest consecutive streak of bullish bars per ticker

ROW_NUMBER() OVER (...) - ROW_NUMBER() OVER (PARTITION BY ticker, is_up ...)

13. LOCAL EXTREMA Run →

Identify local price peaks and troughs across snapshots

LAG(last_price) < last_price AND LEAD(last_price) < last_price

14. ZERO-VARIANCE ISLANDS Run →

Detect stale feeds where price remained identical for >5 updates

GROUP BY consecutive identical values HAVING COUNT(*) >= 5

15. V-SHAPE REVERSALS Run →

Detect V-shape momentum reversals (spike followed by immediate drop)

return_t1 > +5% AND return_t2 < -5%

16. PAIRWISE SELF-JOIN Run →

Find pairs of stocks with identical positive moves at the same timestamp

JOIN stocks a ON a.time = b.time AND a.ticker < b.ticker WHERE ...

17. LAG() TIME-GAP DETECTION Run →

Detect time-series feed gaps > 15 minutes between updates

EXTRACT(EPOCH FROM (last_updated - LAG(last_updated))) > 900

18. CONDITIONAL AGGREGATION PIVOT Run →

Pivot quarterly average price per ticker into separate columns

AVG(CASE WHEN EXTRACT(QUARTER ...) = 1 THEN price END)

19. RECURSIVE SECTOR TREE Run →

Aggregate market cap across parent-child sector hierarchies

WITH RECURSIVE SectorTree AS (...) SELECT root_id, SUM(val)

20. INTERVAL OVERLAP Run →

Check if two scheduled trading halt windows overlap in time

(StartA <= EndB) AND (EndA >= StartB)
